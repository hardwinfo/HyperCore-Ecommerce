# HyperCore E-Commerce

Projeto de E-Commerce Integrado Web + Desktop desenvolvido para fins acadêmicos.

## Sobre o Projeto

O HyperCore é um sistema completo de loja virtual focado em hardware gamer e componentes de informática.

O projeto possui:

* Sistema Web em PHP
* Sistema Desktop Administrativo em C#
* Banco de Dados MySQL
* Integração entre sistemas
* Controle de estoque
* Sistema de pedidos
* Sistema de avaliações
* Carrinho de compras
* Login de clientes
* CRUD administrativo
